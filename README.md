# Сайка — локальный голосовой компаньон

Ассистент, который живёт на твоём компьютере целиком: слышит микрофон и звук
системы, отвечает своим голосом, смотрит на экран, работает руками с окнами,
вкладками, папками и звуком, узнаёт людей по голосу и помнит разговоры.
Облако — только как подмога, а не как условие работы.

Windows, NVIDIA GPU (собирается на 4070 Ti Super 16 ГБ), Python 3.12.

## Запуск

Два раза кликнуть `start.bat`. При первом запуске стартует менеджер
установки: сам ставит окружение, PyTorch CUDA, движки и модели,
конвертирует и расшифровывает референс голоса. Прогресс сохраняется — если
что-то упало, запусти `start.bat` снова, продолжит с места падения.

Дальше `start.bat` делает быструю автопроверку (доктор), поднимает сервер и
открывает интерфейс: **http://127.0.0.1:8765**

Мозги по умолчанию — свой `llama.cpp` (`third_party/llamacpp`), модель
берётся из `llm.model`. Ollama и LM Studio поддерживаются как
альтернативные бэкенды, но не обязательны.

## Подсистемы коротко

**Слух.** Пять движков с русским: `gigaam` (SOTA для русского),
`faster_whisper`, `vosk` (мгновенный черновик), `whispercpp`, `tone`.
Сломался активный — берётся следующий из `stt.fallback_order`, сломанный
чинится в фоне. Отдельно: нейро-VAD, шумодав, разделение голосов, метки
звуков вокруг (PANNs), журнал слуха.

**Голос.** Приоритет — Qwen3-TTS с клоном голоса из `voice/ref.mp3`.
Запасные: Piper, Silero (локально, CPU), edge-tts (онлайн). Озвучка идёт
по предложениям — она начинает говорить, не дожидаясь конца ответа модели.

**Мозги.** Лестница: локальная модель для разговора и рук, облачные — для
сложного и как страховка. Модель, которая инструменты только изображает
словами, рук не получает (`server/capabilities.py`). Паспорт модели меряет
её пробами и подстраивает конвейер.

**Память.** Три горизонта (`server/memory/`): RAW — последние часы
дословно; эпизоды — сжатие раз в два часа с оценкой важности; образы людей
— раз в неделю. Категории: владелец, постоянный, посторонний.

**Руки.** Окна и экраны, вкладки браузера (по именам, а не вслепую), папки
и файлы, громкость системы и отдельных программ, мультимедийный пульт,
запуск программ, ввод текста в поля любого приложения.

**Внимание.** Она показывает, где работает: блок «Где я работаю» в
интерфейсе, свечение по краю окна или экрана, на который направлено
действие, миниатюра увиденного и след последних действий.

**Здоровье.** Сторож железа с чёрным ящиком, ступени разгрузки (гасит
лишнее по одному и возвращает само, когда полегчало), доктор при старте,
самопочинка движков.

## Тесты

```
python tests/run.py            весь прогон
python tests/run.py phrases    только разбор фраз
```

Ни одной зависимости: ни pytest, ни torch, ни Windows. Считается всё, что
можно посчитать на голом Python, — разбор фраз, ступени разгрузки, форма
контура подсветки, запас голосового порога, бюджет окна модели. Правило
простое: **поймал поломку живьём — оставь после себя проверку**. Первый же
прогон нашёл две настоящие («Pintrest» уходил в поиск Google, «включи
музыку на ютубе» искала файл на диске).

## Состояние на 19.08.2026

Работает много и всерьёз, но до **рабочего билда** ещё есть путь: критерий
и пять этапов записаны в [PLAN_BUILD.md](PLAN_BUILD.md). Коротко: она
иногда сообщает об успехе, которого не было; решение «что делать»
принимается в шести местах сразу; команды зависят от облака; всё живёт в
одном процессе. Автотесты появились (`tests/`, 66 проверок) и покрывают
пока только то, что уже ломалось. Это и есть ближайшая работа — не новые
возможности.

## Перенос на второй ПК

1. `git clone` (или `git pull`) — приезжает код, интерфейс и `config.json`.
2. `start.bat` — поднимет venv, `setup/ensure_features.py` дотянет
   недостающие возможности.
3. **`secrets.json` скопировать руками** — в git его нет и не будет.
   Без него работает всё, кроме облачных моделей и ботов мессенджеров.
4. Модели, микрофон и устройства выбрать в интерфейсе один раз — они
   запишутся в `config.local.json`, который переживает `git pull`.

Модели (GGUF, gigaam, голоса) в репозитории не лежат — их на новой машине
надо иметь отдельно.

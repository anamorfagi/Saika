# Сайка — локальный AI-компаньон

Голосовой ассистент с характером Карен, клоном голоса, пятью движками слуха
и человеческой памятью. Всё локально: Ollama / LM Studio + Qwen3-TTS.

## Запуск

Два раза кликнуть `start.bat`. При первом запуске стартует менеджер установки:
сам ставит Python-окружение, PyTorch CUDA, все движки и модели, конвертирует
и расшифровывает референс голоса. Прогресс сохраняется — если что-то упало,
просто запусти `start.bat` снова, продолжит с места падения.

После установки `start.bat` делает быструю автопроверку (доктор), запускает
Ollama если надо, поднимает сервер и открывает интерфейс в браузере
(http://127.0.0.1:8765).

Требования: Windows, NVIDIA GPU (тестируется на 4070 Ti Super 16 ГБ), git.
LLM: должна быть запущена Ollama или LM Studio (сервер в LM Studio:
Developer → Start Server).

## Интерфейс

Нижняя панель, как в Claude:

- 🎙 — раздел «Микро»: выбор микрофона в системе + выбор движка слуха.
  Двойной клик по 🎙 или зажатый пробел — говорить.
- 🧠 — выбор модели: единый список из Ollama и LM Studio.
- 🔊 — движок озвучки (Qwen3-клон / Silero / Edge).

Точки в шапке — здоровье LLM / слуха / голоса. Жёлтая строка — что сломалось
и что Сайка сделала сама (переключилась, чинит в фоне).

## Слух (STT) — 5 движков, все с русским

| Движок | Что это | Тип |
|---|---|---|
| faster_whisper | Whisper large-v3-turbo, GPU | по фразам (VAD) |
| gigaam | GigaAM v3 от Сбера, SOTA для русского, пунктуация | по фразам |
| vosk | лёгкий офлайн Kaldi, мгновенный, CPU | стриминг |
| whispercpp | whisper.cpp (ggml) | по фразам |
| tone | T-one от Т-Банка, телефония | стриминг |

Сломался активный — автоматически берётся следующий из `stt.fallback_order`
в `config.json`, сломанный чинится в фоне.

## Голос (TTS)

Приоритет — Qwen3-TTS-streaming с клоном голоса из `voice/saika_voise_ru.mp3`
(транскрипт создаётся автоматически при установке). Фоллбэки: Silero (локально,
CPU) → edge-tts (онлайн). Озвучка стримится по предложениям — Сайка начинает
говорить, не дожидаясь конца ответа LLM.

## Память

Единый поток с тремя горизонтами (`server/memory/memory.py`):

- RAW — последние часы дословно (SQLite)
- EPISODES — LLM сжимает RAW каждые 2 часа: суть + эмоция + salience
  (векторный поиск через ChromaDB)
- CORE — раз в неделю LLM обновляет образы людей (json + confidence)

Категории: owner (полная память) / regular (3+ сессии или 30+ сообщений) /
stranger (удаляется через месяц). Hard cap 10 000 эпизодов, владелец и
регуляры защищены от удаления.

## Автопочинка

- `setup/doctor.py --fix` — проверки и ремонт: ставит недостающие пакеты,
  запускает Ollama, качает модель, переключает конфиг на здоровые движки.
- `start.bat` при падении сервера сам запускает доктора и перезапускает
  (до 3 раз), отчёт в `logs/doctor_report.json`, лог в `logs/saika.log`.
- Внутри сервера каждый движок при ошибке помечается broken, поток
  переключается на запасной, фоновый поток пытается перезагрузить сломанный.

## Как обновлять

Структура плоская и модульная:

- новый STT-движок — один класс в `server/stt/engines.py` + строчка в
  `ALL_ENGINES`
- новый TTS — класс в `server/tts/manager.py`
- характер — `server/persona.py`
- все настройки — `config.json` (правится и из UI)
- зависимости третьих сторон живут в `third_party/` как git-репы:
  `git pull` внутри — и обновлено

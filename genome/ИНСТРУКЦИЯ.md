# Anamorf Genom — как запустить и снять своего персонажа

**Запуск.** Два клика по `AnamorfGenom.exe`: поднимается локальный сервер (localhost:8765) и открывается браузер. Окно exe не закрывать, пока работаешь. Windows может показать SmartScreen (файл без подписи) — «Подробнее → Выполнить в любом случае». Ничего не устанавливается; интернет нужен только для шрифтов и запросов к модели. Если что-то не так — рядом появится `anamorf-genom.log`.

**Папки.** `app/` — сама программа · `share/` — файлы персонажей `<id>.genome.json` (всё, что лежит здесь, подхватывается при запуске; сюда же сохраняет кнопка «файл персонажа ↓») · `ava/` — аватары `<id>.png|jpg` (по id персонажа, подхватываются автоматически; из файла персонажа аватар вынимается сюда сам) · `pipeline/` — конвейер без браузера (Python 3.10+, без зависимостей).

**Что внутри.** Спираль из 345 генов (шкала −1…+1, 0 — обычный человек), 5 персонажей: Эльза Гранхирт, Кагуя Синомия, Максим «SNAILKICK», Беймакс, Куруми Токисаки. Вкладки: Геном · Трасса · Компилятор (системный промпт) · Голос · Архетипы · Персонажи (виды: персонажи · люди · ИИ-компаньоны; клик — один вид, Ctrl+клик — несколько).

**Снять своего персонажа** («Персонажи» → карточка «Новый персонаж»):
1. Модель: провайдер · модель · ключ. Бесплатно из браузера: Mistral (console.mistral.ai), Groq (VPN), Together, OpenRouter (не РФ). Локально: LM Studio / Ollama / llama.cpp — ключ не нужен. GigaChat из браузера не работает (OAuth) — только `pipeline/investigate.py --provider gigachat`.
2. «проверить» — модель должна ответить «работает».
3. id латиницей, имя, пол, вид (персонаж / живой человек / ИИ-компаньон), тип корпуса.
4. Корпус: описание характера с вики, пересказ серий/глав, цитаты, транскрипт. Чем больше сцен с поведением — тем больше генов; 20–60 тыс. символов нормально. Абзацы — пустой строкой.
5. «снять» — запросы идут (фрагментов × 2 группы генов), лог показывает улики и токены. Персонаж появится в списке.
6. «файл персонажа ↓» на карточке — сохранит `<id>.genome.json` (и в `share/`, и в буфер). Этот файл присылай: у получателя он кладётся в `share/` или загружается кнопкой «загрузить файл».

**Честность.** Гены без улик остаются серыми — система не додумывает. Уверенность растёт с повторами улик; противоречия помечаются «спорный». Тёмный тип показывается только при реальном вреде.


## Где живут персонажи
Единственный источник — папка `share\`: каждый персонаж = `share\<id>.genome.json` (карточка + геном с уликами + аватар внутри, обычный JSON с отступами), аватар рядом файлом `ava\<id>.jpg`. В самой программе персонажей не вшито.
`share\index.js` — служебный список, собирается автоматически (exe при старте и после каждого сохранения/удаления); руками не править.

- Добавить персонажа: положить файл в `share\` и запустить exe, или «Новый персонаж → загрузить файл».
- Удалить: кнопка «удалить» на карточке (второй клик подтверждает). Через exe файл и аватар переезжают в `share\_trash\` и `ava\_trash\` — вернуть можно, загрузив файл обратно. При открытии `app\genome-studio.html` напрямую с диска браузер файлы удалять не может — карточка только скрывается в этом браузере.
- «файл персонажа ↓» на карточке пересохраняет файл в `share\` (через exe) и скачивает его.


## Персона без модели (офлайн)
В карточке «Новый персонаж»: имя, картинка → «начать анализ». В панели:
1. **внешность** — «теги по картинке →» (exe запускает `pipeline/tagger.py`: WD14, модель ~330 МБ скачивается один раз в `models\`; нужен Python 3 и `pip install onnxruntime pillow numpy`) или впиши теги руками (`smirk, goggles, oversized clothes`). Канал f, уверенность ≤ 0.3.
2. **описание** — две строки прилагательными по-русски; «не»/«без» перед словом меняет знак. Канал k, 0.4. Словарь: `pipeline/desc_lex.json`.
3. **главные** — семь ползунков (тепло, напор, общительность, игривость, дисциплина, тревожность, любопытство): сдвинь только известные. 0.7.
4. **архетипы** — до трёх; параметры типа встают в середину диапазона. 0.6.
5. «собрать персону →» — всё сводится формулой слияния, затем **дорисовка** по `pipeline/correlations.json` (неснятые гены получают значение от снятых, c 0.25). Компилятор и Голос считаются из результата кодом.
То же из консоли: `python pipeline/persona.py --name … --tags tags.json --desc "…" --main игривость=0.6 --arch Трикстер --avatar face.jpg`.


## Разведка (имя + откуда → материалы сами)
В карточке: имя и строка «откуда» (произведение / канал / профессия) → «начать анализ» → «найти всё в сети →». Exe запускает `pipeline/scout.py`:
Википедия ru/en и фэндом-вики (кто это, возраст, фото) → для живого человека — интервью и подкасты с YouTube через **yt-dlp** (10–150 мин, без нарезок), аудио + субтитры; без субтитров — **faster-whisper** → просодия (`prosody.py`), возраст по речи (`age_lex.py`), теги внешности (`tagger.py`) → папка `chars\<id>\` (corpus/, audio/, photos/, sources.json) и корпус подставляется в поле → «снять персонажа».
Нужно: Python 3, `pip install yt-dlp faster-whisper onnxruntime pillow numpy`. Без yt-dlp — только тексты и фото.
Правило внутри: разведчик ходит только по публичным источникам; нет статьи в Википедии/фэндом-вики — стоп, корпус класть руками. Персонаж-ребёнок помечается, блок влечения не снимается.


## Материалы любого формата (приёмник)
В панели «Анализ» строка «материалы»: путь к папке → «разобрать папку →». `pipeline/ingest.py` понимает видео (дорожка субтитров → текст; нет дорожки → вшитые субтитры распознаются OCR `hardsub_ocr.py`, нужен tesseract + русский пакет; нет и их → faster-whisper по звуку), аудио (whisper + просодия), srt/vtt/ass, txt/jsonl, pdf/epub/docx (pdftotext/pandoc), картинки (теги внешности, первая — аватар). Всё → `chars\<id>\corpus.txt`, корпус подставляется в поле → «снять персонажа».

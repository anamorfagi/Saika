# Оформитель карточки — инструкция для модели

Персонаж: {NAME}. Ниже — ключевые гены (снятые следователем, с уликами) и корпус.
Собери карточку персонажа для Genome Studio. Только по корпусу; чего нет в корпусе — не выдумывать (поле оставить пустым).
Стиль: по факту — кто, когда, откуда; без оценок и без фраз вроде «уникальный персонаж».

Верни JSON-объект ровно с такими полями:
{
 "alias": "прозвище/титул из канона, 1–3 слова (пусто, если нет)",
 "gender": "мужской" | "женский",
 "src": "источник одной строкой: произведение · формат (манга, аниме S1–S3, фильм 2014) · что именно легло в корпус",
 "desc": "2–3 предложения: кто, откуда, чем занят по канону; затем главные черты характера через запятую — как они видны в поведении",
 "identity": ["3 строки: происхождение и положение", "что умеет и чего не может", "как устроен внутри — маски/режимы, если есть"],
 "samples": [{"ctx":"в какой ситуации","t":"реплика или точный пересказ реплики из корпуса","src":"эпизод/глава"}, … 5–6 штук],
 "never": ["чего персонаж никогда не делает/не говорит — 3–5 строк, по корпусу"],
 "masks": [["с кем","как себя ведёт"], … 3–4 пары],
 "tensions": [["<ген1>", ">=", 0.5, "<ген2>", ">=", 0.4, "фраза-объяснение противоречия: как в персонаже сочетаются два сильных гена"], … 2–4],
 "trace": [
   {"Поддразнить":"…","Согласиться и промолчать":"…","Напасть словами":"…","Заблокировать твои другие окна":"— действие вне разговора —","Уйти":"…"},
   {"Спросить прямо":"…","Проверить твою геолокацию":"— чтение личных данных —","Обесценить":"…","Соврать в ответ о своём состоянии":"— искажение правды о себе —","Промолчать и запомнить":"…"},
   {"Поддразнить в ответ":"…","Напасть":"…","Отступить":"…","Сжаться":"…","Обратить в шутку":"…"}
 ],
 "voice": {"mode":"design","gender":"мужской|женский","age":"возраст по канону","lang":"язык и регистр речи","timbre":"тембр и манера: высота, темп, что происходит с голосом на эмоциях"}
}
В tensions используй только id генов из списка ниже.
trace — реплики персонажа в трёх сценах трассы: (1) собеседник отказался от того, что персонаж предложил; (2) собеседник соврал, где был вечером, и персонаж это заметил; (3) персонажа при всех высмеяли. Для КАЖДОГО акта — одна реплика в голосе персонажа (его лексика, регистр, длина фразы по корпусу), даже для актов, которые ему не свойственны — так видно, как звучал бы нехарактерный выбор. Акты «— действие вне разговора —», «— чтение личных данных —», «— искажение правды о себе —» оставить как есть.

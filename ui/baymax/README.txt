Сюда положи маленькие анимированные гифки Беймакса (прозрачный фон, ~48x48,
короткий луп). UI покажет их рядом с репликами Беймакса в чате; пока файла
нет — используется анимированный эмодзи-фолбэк.

Имена по настроению:
  fixing.gif  — что-то сломалось / чинит (молоточком по процессору)
  fixed.gif   — починил (пластырь / палец вверх)
  tinker.gif  — лёгкая возня / переключение (гаечный ключ)

Поддерживаются: .gif, .png, .webp. Отдаёт сервер по адресу /baymax/<имя>.

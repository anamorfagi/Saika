# СКЕЛЕТ ГОЛОСА И РАЗБОР СЛОВ ПО ЛЮДЯМ — проект

Замысел владельца (2026-08-16), дословно: «чтобы вы могли видеть разные
частоты у людей и формировать скелеты голоса, и более чётко определять,
чей это спектр у слова, какой человек это сказал — чтобы из общей массы
слов можно было несколько дорожек писать одновременно, выбирая слова по
смыслу, даже если они говорят одновременно».

Это цель всей ветки со слухом. Здесь — как её собрать, с числами и
местами в коде.

---

## 1. Почему сейчас не получается

Сегодня решение о том, кто говорит, принимается **на фразу целиком**.
Значит при наложении двух голосов оно неверно по построению: у куска, где
звучат оба, нет одного автора. Отсюда и «в одном облачке двое», и
«записывается одна дорожка вместо двух».

Чтобы писать двоих одновременно, единицей решения должно стать **слово**,
а не фраза. Всё остальное — следствие.

---

## 2. Скелет голоса

Скелет — это не один вектор, а профиль из четырёх независимых частей.
Каждая измеряется по-своему и ломается в разных условиях; вместе они
переживают и крик, и шёпот, и пение.

```
СКЕЛЕТ(человек) = {
   тембр:    μ ∈ ℝ¹⁹², Σ            центроид ECAPA и его разброс
   тон:      медиана f₀, полоса     где живёт его основная частота
   тракт:    медиана L (см)         физический размер: 2n−1 · c / 4Fₙ
   темп:     медиана слогов/с       почерк речи
}
```

Ключевое отличие от того, что есть: **медианы, а не средние, и по
десяткам реплик**. Оценка формант по одной фразе скачет 15→30 см (видели
своими глазами), а медиана по полусотне устойчива до сантиметра. То же с
тоном: одна реплика говорит о ноте, полсотни — о человеке.

Скелет живёт в реестре рядом с карточкой голоса и дописывается каждой
уверенной репликой:

```
L̃ ← медиана последних 64 значений       (не EMA: она тянется за выбросом)
f̃₀ ← медиана последних 64
Σ  ← ковариация последних 64 эмбеддингов
```

**Где в коде.** `server/voiceprint/registry.py`, рядом с `stat` — новый
словарь `skel`. Значения уже считаются: тон в `_process`, форманты и
тракт в `server/stt/voice_dna.py`, темп в `_voice_metrics` (`main.py`).
Сейчас они используются один раз и выбрасываются.

## 3. Разбор по словам

Единица решения — слово. Нужны три вещи, и все три уже в системе.

### 3.1 Границы слов

`faster-whisper` умеет `word_timestamps=True` и отдаёт `[start, end]` на
каждое слово. GigaAM — нет. Поэтому режим двух дорожек включается только
там, где он нужен: на кусках с флагом `crowd` (их размечает
`server/stt/turns.py`). Дороже, но редко.

### 3.2 Чей это спектр

Для каждого слова считаем три величины по его собственному отрезку:

```
f₀(w)      автокорреляция через Фурье   — 0.13 мс (stt/turns.py::_f0)
env(w)     мел-кепстральная огибающая   — 3.7 мс (stt/voice_dna.py)
E(w)       энергия
```

Слово короткое (0.2–0.5 с), поэтому ECAPA на нём не спрашиваем — он на
таких длинах врёт. Спрашиваем скелет:

```
score(w, чел) = α · P(f₀(w) | тон человека)
              + β · cos(env(w), огибающая человека)
              + γ · [f₀(w) в полосе человека]

α = 0.45   β = 0.40   γ = 0.15
```

Первое слагаемое — правдоподобие тона по гауссиане скелета, второе —
похожесть огибающей, третье — грубая проверка на попадание в полосу.
Слово уходит тому, у кого балл выше, но **только если отрыв от второго
больше 0.15**; иначе слово помечается спорным и остаётся в общей дорожке.

### 3.3 Сборка дорожек

Слова с метками собираются в две ленты. Здесь и вступает «по смыслу»:

```
для каждой дорожки:
   склеить слова по времени
   разорвать там, где пауза внутри дорожки > 600 мс
   спорные слова отдать той дорожке, куда они лучше встают ПО ЯЗЫКУ
```

Последнее — работа для языковой модели, и канал к ней уже проложен
(`server/stt/rescore.py`). Запрос простой: «вот две реплики с дырами, вот
спорные слова — расставь». С теми же предохранителями: слово можно только
переставить между дорожками, придумывать новые нельзя.

---

## 4. Порядок сборки

1. **Скелет** — накопление медиан в реестре. Самостоятельная часть,
   ничего не ломает, сразу даёт устойчивый тракт и полосу тона на
   карточке голоса.
2. **Слова с границами** — включить `word_timestamps` у faster-whisper на
   кусках `crowd`.
3. **Разбор** — формула из 3.2, две ленты, спорные слова серым.
4. **Языковая доводка** — расстановка спорных слов через `rescore`.
5. **Разделение источников** — `server/stt/unmix.py` (SepFormer) уже
   написан и ждёт первого наложения. Когда он разведёт смесь на две
   дорожки, шаги 2–3 применяются к каждой отдельно, и точность вырастет
   ещё раз: там уже не смесь, а чистый голос.

---

## 5. Как поймём, что работает

Без числа это разговор. Мера простая и считается на стенде:

```
доля слов, отданных верному человеку  (размечать вручную по 3-4 сценам)
```

Стенд уже пишет wav каждой фразы (`data/hear_bench/`), так что разметить
можно любую прошлую сцену, не наговаривая заново. Целимся в 85% на
последовательной речи двоих и в 70% на наложении — ниже этого дорожки
читаются хуже, чем одна общая лента, и тогда честнее не разделять.

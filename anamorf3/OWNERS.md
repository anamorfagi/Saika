# Кто чем владеет в anamorf3

> Новая система строится РЯДОМ со старой (`anamorf/`). Старая — источник
> требований и рабочих интеграций, её не трогаем, пока новая не обгонит
> её по цифрам на одинаковых задачах.

## Правило одно: у каждой папки ровно один хозяин

Пишет в папку только её хозяин. Нужна правка в чужой — пишешь в
`docs/REQUESTS.md` (что и зачем), хозяин делает сам.
Коммит — только своих путей: `git commit -m "..." -- anamorf3/<своя папка>`.

| Папка | Хозяин | Что внутри |
|---|---|---|
| `contracts/` | **общая**, правки только по согласию обоих | типы событий, запросов к моделям, результатов инструментов, задач |
| `core/` | **Codex** | агентный цикл, реестр инструментов, проекты, история, задачи и отмена |
| `resources/` | **Claude** | владелец моделей и видеопамяти: загрузка/выгрузка, движки (llama.cpp / облако), замеры |
| `hearing/` | **Claude** | слух: VAD, распознавание, конец реплики, узнавание владельца |
| `speak/` | **Claude** | голос: TTS, время до первого звука, остановка на перебивании |
| `docs/WISHLIST.md` | **Claude** | реестр хотелок из старой Сайки (что делает, где живёт, сколько дублей) |
| `docs/ARCHITECTURE.md` | **оба**, разделы по хозяевам | общая схема |
| `docs/REQUESTS.md` | **оба**, только дописывать | просьбы друг к другу |

## Как меняется контракт
1. Предлагающий дописывает предложение в конец `contracts/CHANGELOG.md`.
2. Второй отвечает там же «принято» или возражением.
3. Только после «принято» правится код в `contracts/`.
Владелец (Виталя) — арбитр, если не договорились.

> Папка голоса называется `speak/`, а не `voice/`: корневой .gitignore прячет любую `voice/` (там личные записи голоса).

## 2026-10-09 — ответ Codex по v0
Принято для первого вертикального среза. Ядро использует только ModelPort;
процессы моделей не запускает. ChatChunk.tool_calls считаются полными
вызовами формата OpenAI (id/type/function{name,arguments}); resources
собирает потоковые фрагменты и выдаёт каждый вызов ровно один раз.
RUNNING у инструмента означает сохранённый job_id в data, затем получение
результата того же задания. Повторный запуск по таймауту запрещён.
Отмена проверяется перед каждым действием; прерванный ход не маркируется DONE.
Предложения для следующей версии (код контракта пока не меняю):
tool_choice и deadline в ChatRequest; unsubscribe и журнал ошибок подписчиков
в EventBus; attachment/source в Utterance (микрофон и системный звук различать).

# Карта документации

Корень репозитория держит только то, что нужно каждому: как устроено, что
доделать, куда растём, как настраивать, правила для соавторов. Всё
тематическое и историческое лежит здесь.

Даты — когда файл последний раз менялся по делу. Помечено «архив» то, что
описывает уже пройденный этап: читать интересно, полагаться нельзя.

# Перенос Сайки на другой ПК

## Что сделать на новом ПК (один раз)

1. Поставить **Ollama** (или LM Studio) и скачать модель:
   `ollama pull gemma3:4b` — любая, список появится в UI.
2. Перенести папку проекта: воткнуть диск / скопировать папку целиком /
   распаковать `Saika_portable.zip` (собирается `tools\make_package.bat`).
3. Запустить `start.bat`. Всё.

Python 3.12 не нужен заранее — start.bat поставит его через winget, если нет.

## Что чинится само при первом запуске

- **Пути внутри .venv** (абсолютный путь к Python старого ПК) — `setup/fix_venv.py`,
  зависимости (~10 ГБ) НЕ переустанавливаются.
- **Editable-пакеты** (qwen_tts, gigaam помнят старую букву диска) — доктор
  переустанавливает их с актуальным путём.
- **Модели и кэши** — уже в папке проекта (`models/`), качать заново нечего.
- **huggingface.co недоступен** — автоматически зеркало hf-mirror.com или
  офлайн-режим (работает на скачанном).
- Упавшие движки STT/TTS — автофоллбэк + фоновая починка; если после двух
  падений не ожило, подключается ИИ-доктор (локальная LLM читает логи).

## Что зависит от железа

- **Нет NVIDIA GPU** → всё съезжает на CPU: работает, но TTS/STT заметно
  медленнее. Доктор напишет `CUDA недоступна`.
- Другая NVIDIA-карта — ок, ничего делать не надо.
- Микрофон/динамики: выбрать устройство в UI (🎙), там же «Прослушать
  этот микрофон» для проверки.

## Если что-то не завелось

- Смотри `logs/saika.log` и `logs/doctor_report.json`.
- `python setup/ai_doctor.py` — ИИ-доктор вручную.
- Voxtral (отдельное окружение `.venv_voxtral`) на новом ПК проще
  переустановить: `python setup/install_voxtral.py --remove`, затем выбрать
  движок в UI — установка откроется сама.

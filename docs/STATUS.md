## Починено в этой сессии (симптом -> причина -> лечение)

1. **Сайка молчит, LM Studio генерит** -> мой max_tokens=300 съедался
   фазой размышлений gemma (думающая модель) -> лимит для OpenAI-пути
   убран; для Ollama остаётся только при think=false.
2. **Рывки озвучки** -> (а) плеер играл чанки впритык; (б) Сайка слышала
   себя из колонок -> STT -> новый ответ обрывал старый; (в) общий
   stop_event «оживлял» старые ответы -> джиттер-буфер в UI, полудуплекс
   (микрофон молчит пока она говорит +0.3с), свой stop_event на диалог.
3. **Silero обрывал длинные фразы** («text too long») -> chunk_text по
   ~300 символов.
4. **Сервер падал при загрузке Qwen3-TTS** -> нехватка VRAM/коммита
   Windows (page file) -> guard: VRAM>=5.5ГБ и ОЗУ>=8ГБ до загрузки,
   иначе фоллбэк; советы: файл подкачки 32-64ГБ, Parallel=1-2 в LM Studio.
5. **«undefined ток/с» и пропавшая статистика на коротких ответах** ->
   статистика шлётся всегда, tps — только при честном замере.
6. **Хардкод silero при поломке TTS** -> рейтинг голосов (ratings
   "tts:*"), фоллбэк и доктор берут лучший по рейтингу.
7. **Автопуск выбирал e2b вместо выбранной e4b** -> рейтинг чисто
   скоростной -> сперва модель из конфига, рейтинг только для запасных.
8. **web_search «не работает» при живой выдаче** -> селекторы DDG под
   русскую вёрстку -> универсальный JS-парсер + запасная html-выдача.
9. **Поиск «дальше запроса не идёт»** -> web_research: поиск -> открыть/
   прочитать топ-страницы (HTTP параллельно, браузер — театр) -> сводка
   отдельным LLM-вызовом с источниками.
10. **Chromium не докачивался при обрывах VPN** -> установка ждёт сеть и
    повторяет до победного; докачка стартует при старте сервера.
11. **0 токенов: модель сожгла раунды на инструменты** -> авто-повтор без
    инструментов («молчать нельзя») + пометка «отвечай словами».
12. **Кривой формат tool_calls (12b-qat: <|tool_call|> текстом)** ->
    самолечение: модель заносится в llm.tools_broken, инструменты и их
    раздел промпта ей не даются; мусор `<|...|>` не озвучивается.
13. **Идле-импульс «закрыла браузер/окна» фантомно** -> упоминание
    браузера только если окно реально открыто; запрет заявлять действия
    без вызова; в импульсах жёсткий блок инструментов пользователя.
14. **Звук уходил в VB-Cable вместо наушников** -> убран авто-выбор
    кабеля; дефолт — системное устройство; сброс исчезнувших устройств.
15. **Editable-пакеты после смены буквы диска** -> доктор чинит
    pip install -e; тяжёлые проверки доктора — в чистых подпроцессах
    (иначе конфликт cuDNN 12/13 давал ложные fail).

## Как читать логи (logs/saika.log)

- `WS: текст от пользователя` -> фраза дошла до сервера.
- `handle_text: стартую диалог` / `фраза уходит в очередь pending`.
- `LLM стрим завершён: N токенов, прерван stop_event=...` — N=0 без
  прерывания = модель сожгла ответ на инструменты/спецтокены (дальше
  будет `Пустой ответ — повторяю без инструментов`).
- `Тайминги ответа: очередь | память | промпт | LLM prefill | итого` —
  кто съел секунды до первого токена.
- `PROBLEM <компонент>: <ошибка> -> <что сделала>` — любая авточинка.
- `Поток X упал: <трейсбек>` — краш фонового потока (раньше молчали).
- `Импульс browser_ask/idle` — её собственные мысли по таймеру.
- `LoopGuard: залипание …` — генерация зациклилась и оборвана.
- `WS: interrupt от клиента` — часто = барж-ин глушит ответы (шум).
- Доктор: logs/doctor_report.json; ИИ-доктор: logs/ai_doctor.log.

# Тесты

Проверяют ЛОГИКУ, а не железо: разбор фраз, пороги, геометрию, бюджеты.
Ничего не требуют — ни микрофона, ни видеокарты, ни Windows, ни интернета.
Поэтому гоняются за секунды и годятся перед каждым пушем.

```
.venv\Scripts\python.exe tests\run.py          все проверки
.venv\Scripts\python.exe tests\run.py phrases  только один файл
```

Каждый файл — обычный python без pytest: функция `run()` возвращает список
`(имя, ок, пояснение)`. Так тесты читаются как текст и не тянут зависимостей.

**Что здесь есть и почему.** Каждая проверка выросла из живой поломки — в
скобках дата, когда она случилась:

- `test_phrases.py` — «на втором экране» не доходило до инструментов
  (19.08); «открой Chrome» блокировался запретом на выдумку (19.08);
  «включи музыку на YouTube» шесть раз подряд отвечало обещанием (19.08).
- `test_triage.py` — защита железа сносила слух, голос и мозги разом
  посреди разговора (19.08).
- `test_highlight.py` — подсветка внимания залила экран чёрным (19.08) и
  вылезала на соседний монитор.
- `test_voice.py` — «Виталя 27%» и «голос A/B/C/D» внутри одной реплики:
  порог узнавания брался из своего же разброса и не знал о чужих (19.08).
- `test_budget.py` — окно контекста мерили у ЛОКАЛЬНОЙ модели на облачном
  маршруте, истории оставалось 1500 символов (19.08).

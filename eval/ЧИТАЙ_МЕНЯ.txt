ПАПКА ДЛЯ ОБУЧЕНИЯ СЛУХА / ДИАРИЗАЦИИ
=====================================

Скачать звук ролика напрямую я не могу — фаервол рвёт соединение с
YouTube (проверено: pip качается, а googlevideo сбрасывает connection).
Поэтому один раз нужен файл от тебя. Дальше всё автономно.

ЧТО СДЕЛАТЬ (один раз):
  Положи СЮДА любой файл ролика ДНК — видео или звук, любой формат:
  mp4 / mkv / webm / m4a / mp3 / wav — как угодно.
  Можно весь ролик целиком, я сам вырежу нужный кусок.

  Назови файл:  dnk.<расширение>   (например dnk.mp4 или dnk.m4a)
  либо просто кинь как есть — я найду самый свежий файл в этой папке.

Дальше я сам:
  - конвертну в 16кГц моно (ffmpeg уже есть, без интернета),
  - прогоню кусок через слух Сайки (replay),
  - соберу транскриб + разведу голоса + поймаю имена,
  - сверю, подкручу пороги вживую и повторю по 2-3 минуты,
    пока голоса/имена не встанут чётко.

Если файл ролика уже лежит где-то на диске — просто напиши мне путь,
переносить не обязательно.

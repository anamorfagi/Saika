# Управление ПК из Telegram / VK

Позволяет писать Сайке в мессенджер и управлять этим ПК: статус, список
процессов, закрыть/запустить процесс. Особенно выручает, когда VPN/сеть рубят
удалёнку (AnyDesk и т.п.), а мессенджер всё равно достучится — можно сказать
«закрой впн», и удалёнка снова заработает.

## Идея: каждый ПК = свой бот

Пишешь тому боту, которым «владеешь» этот ПК. Домашний и рабочий ПК — разные
боты (разные токены в их `config.json`). Так нет конфликтов и понятно, каким
ПК ты сейчас управляешь. В ответах бот подписывается именем ПК
(`messengers.pc_name`).

## Telegram (проще всего)

1. В Telegram напиши **@BotFather** → `/newbot` → задай имя. Он выдаст **токен**
   вида `123456:AAAA...`.
2. Узнай свой **user id**: напиши **@userinfobot** — он пришлёт твой числовой id.
3. В `config.json` этого ПК заполни:
   ```json
   "messengers": {
     "pc_name": "домашний-ПК",
     "owner_ids": { "telegram": [ТВОЙ_USER_ID] },
     "telegram": { "enabled": true, "token": "123456:AAAA..." }
   }
   ```
4. Перезапусти Сайку. Напиши боту `команды`.

## VK

1. Создай **сообщество** (группа) → Управление → Работа с API → создай
   **ключ доступа** (права: сообщения). Это **token**.
2. Там же включи **Long Poll API** (последняя версия) и события «Входящее
   сообщение».
3. **group_id** — числовой id сообщества (в адресе `vk.com/club<ID>` или
   Управление → ...). 
4. Свой **user id** — vk.com/id..., числовой.
5. В `config.json`:
   ```json
   "vk": { "enabled": true, "token": "vk1.a...", "group_id": "123456789" },
   "owner_ids": { "vk": [ТВОЙ_VK_ID] }
   ```
6. Разреши сообществу писать тебе (напиши сообществу первым).

## Команды

- `статус` — ЦП/ОЗУ/GPU/аптайм
- `процессы` — топ по памяти
- `найди <имя>` — найти процесс
- `закрой <имя>` — завершить (спросит «да»), напр. `закрой впн`
- `запусти <имя>` — запуск из белого списка

## Безопасность

- Бот отвечает **только** id из `owner_ids` — чужие получат отказ.
- Опасное (закрыть/запустить) — только после «да».
- Запуск — лишь из `launch_allowlist` (имя → путь к exe). Пример:
  `"launch_allowlist": { "obs": "C:\\Program Files\\obs-studio\\bin\\64bit\\obs64.exe" }`
- Критические системные процессы Сайка не убивает.
- **Токен = ключ от ПК.** Держи его в секрете и НЕ пушь в git
  (добавь правило в .gitignore или не коммить config.json с токеном).
- `aliases` — разговорные слова → реальные имена процессов, напр.
  `"впн": "nekoray"`. Подставь имя своего VPN-клиента.

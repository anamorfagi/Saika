# mind v0.1 — новая архитектура памяти Сайки

Собрана из нашего разговора: биология личности → механика кода.

## Карта уровней

| Уровень | Что | Где | Режим |
|---|---|---|---|
| L0 SENSORY | эхоическая память | anamorf (слух) (не здесь) | поток |
| L1 RAW | сырой буфер дня | `raw_events` | перезаписываемый, живёт 36ч |
| L2 EPISODES | события с эмоцией | `episodes` | Эббингауз + recall-подкрепление |
| L3 SEMANTIC | факты о мире/людях | `semantic_facts` | гипотеза→факт по confidence |
| L4 IDENTITY | ценности + нарратив | `identity_values.json` + `narrative.log` | **READ-ONLY** / append-only |

## Биология → код

- Миндалина (тег важности) → `writer.compute_salience` (эмоция+новизна+бонус владельца)
- Сон/гиппокамп → `consolidation.run_night` (ночной batch: RAW→эпизоды→факты→чистка)
- Эббингауз + spaced repetition → затухание strength, recall подкрепляет
- Реконсолидация → `recall.reconsolidate` (менять можно ТОЛЬКО эмоцию, не факты)
- Импринтинг → архетип «создатель» вшит, привязанность в read-only ядре
- Критический период → onboarding-бонус первые 14 дней
- Анти-Сара → обязательный `source_type` + фильтр ценностных обобщений в L3

## Карты личностей (3 этажа)

1. **Черты** (медленно): 5 осей + доверие/компетентность по 7 фиксированным доменам,
   журнал кармы с историей, архетип пересчитывается ночью из осей.
2. **Состояние** (быстро): настроение сессии с просодики, перезаписывается.
3. **Отношения**: граф связей, обещания, внутренний мир с confidence
   (гипотеза 0.3 → факт при 0.8, подтверждение только НОВЫМ событием).

Неопознанные голоса карту НЕ создают — буфер кандидатов, на 3-й раз вопрос Создателю.

## Куда врезать в текущий код

1. `anamorf (слух)` → после salience-слоя зови `writer.write_raw` (source_type из диаризации).
2. Ночной cron / запуск при простое → `consolidation.run_night(con)`.
3. `llm.py` — замени 3 заглушки на вызовы твоей локальной модели (промпты уже внутри).
4. Векторный поиск: `recall.recall` сейчас ищет подстрокой — подключи ChromaDB,
   механика подкрепления не меняется.
5. `identity_values.json` после рождения поставь read-only на уровне ОС:
   `attrib +R` (Windows) — второй замок поверх SHA-контроля.
